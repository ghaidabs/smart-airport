# rt/

**Responsable : P3.** Modélisation temps réel, threads et mesures.

Fichiers prévus :

- `tasks.py` : table des tâches (`TaskSpec`).
- `periodic.py` : `PeriodicTask`, avec dates de réveil absolues.
- `sporadic.py` : `SporadicTask`, avec intervalle minimal entre arrivées.
- `metrics.py` : collecte CSV et résumé (Cmin, Cmoy, Cmax, Rmax, dépassements, gigue max).
- `periodic_c/` : bonus, tâche périodique en C.

Référence : annexe B du guide et table des tâches v0 (section 4).
