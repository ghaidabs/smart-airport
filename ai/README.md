# ai/

**Responsable : P2.** Données, modèle de risque et réentraînement.

Fichiers prévus :

- `generate_data.py` : simulation d'environ 20 000 situations de correspondance.
- `train.py` : entraînement et évaluation du modèle.
- `predictor.py` : classe `RiskPredictor` (contrat en annexe B).
- `retrain_cloud.py` : tâche T6, réentraînement hors du chemin critique.
- `models/` : modèle entraîné et métadonnées.
